# Arduino Water Detection Sensor

A simple **Arduino UNO** project that detects the presence of water (leaks or flooding) using a water level sensor and triggers an audible alarm via a **beeper/buzzer**.

## Components

*   **Arduino UNO** (or any compatible board)
*   **Water Level/Detection Sensor**
*   **Active or Passive Buzzer** (Beeper)
*   Jumper wires (Dupont cables)
